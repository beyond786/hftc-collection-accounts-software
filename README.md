# HF TC — Collection & Accounts Software (Angular)

**ہمدرد فوجی ٹریڈنگ کارپوریشن (HF TC)** کے **Head Office** کے لیے جدید **Angular** پر مبنی **collection / accounts / inventory / printing** ایپلیکیشن۔

---

## ✨ خصوصیات (Features)

| ماڈیول | تفصیل |
|---|---|
| **ڈیش بورڈ (Dashboard)** | کل وصولی باقی، آج اور اس ماہ کی وصولی، کیش بیلنس، کھاتے (فعال و بند)، ڈیفالٹرز اور اسٹاک مالیت کے لائیو کارڈز |
| **کھاتے / گاہک (Customers & Accounts)** | مکمل اقرار نامہ کے تمام 20+ fields (نام، ولدیت، قوم، مستقل و موجودہ پتہ، 13 ہندسوں والا شناختی کارڈ، ضامن کی مکمل تفصیل) + خودکار بقایا حساب کتاب |
| **وصولی / رسید (Collection & Receipts)** | فاسٹ کاؤنٹر قسط وصولی، خودکار لیٹ قسط جرمانہ کاؤنٹر، خودکار رسید نمبر، لیجر کارڈ اندراج، اور فوری رسید پرنٹ |
| **اسٹاک / اشیاء (Inventory Master)** | اشیاء کی ماسٹر لسٹ، خریداری، فروخت، واپسی و ایڈجسٹمنٹ موومنٹس، ری آرڈر لیول الرٹس |
| **حسابات و اخراجات (Cash Book & Expenses)** | روزنامچہ (Daily Running Cash Book)، آمد و خرچ اندراج، دفتری اخراجات مع کیٹیگریز (تنخواہ، کرایہ، پٹرول، اسٹیشنری) |
| **رپورٹس و پرنٹ (Reports & Printouts)** | روزانہ وصولی شیٹ، بقایا کھاتے، ڈیفالٹرز، اسٹاک رپورٹ، ریکوری اسٹاف کارکردگی اور منافع و نقصان خلاصہ |
| **ترتیبات و بیک اپ (Settings & Backup)** | کمپنی پروفائل، لیٹ جرمانہ شرح، برانچز، JSON بیک اپ ڈاؤن لوڈ و اپلوڈ، اور ڈیمو ڈیٹا ری سیٹ |

## 🖨️ پرنٹ آؤٹس (Paper Forms)

تینوں اصل کاغذی فارمز کے عین مطابق پرنٹ آؤٹس:

1. **رسید (Receipt)** — HF TC لوگو، میر پور ماتھیلو ہیڈ آفس، فون نمبرز، رسید نمبر، سیریل نمبر، کارڈ نمبر، نام و ولدیت، اشیاء، مبلغ، بقایا، باکس کوڈ (U-01)، رقم بالفاظ اردو ("بارہ سو پچاس روپے فقط")، دستخط منیجر و وصول کنندہ، اور لیٹ جرمانہ نوٹ۔
2. **اقرار نامہ (Agreement)** — درخواست دہندہ اور ضامن کے لیے 15 خانے دار این آئی سی گرڈ، مکمل کوائف، مالیاتی شرائط، اور دستخط خریدار و ضامن۔
3. **کھاتا کارڈ (20-Row Ledger Card)** — نمبر، دستخط، ماہ، جمع، بقایا، رسید، تاریخ اور دستخط OM پر مشتمل 20 قطاروں والا مستند کارڈ۔
